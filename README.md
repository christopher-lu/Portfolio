# Project Structure
```

app/
components/
data/
hooks/
public/
styles/
types/

````

### app/

Application routes using the Next.js App Router.

### components/

Reusable UI and page components.

### data/

Centralized content powering projects, publications, navigation, and other reusable data.

### hooks/

Custom React Hooks used throughout the application.

### public/

Static assets including images, icons, and downloadable files.

### styles/

Global styling and design tokens.

### types/

Shared TypeScript interfaces and type definitions.

---

# Design Philosophy

The project follows several engineering principles:

- Separation of concerns
- Strong typing
- Component reusability
- Consistent design system
- Minimal prop drilling
- Scalable file organization
- Accessibility-first development

As the project grows, new sections can be added without requiring significant architectural changes.

# Local Development

Clone the repository

```bash
git clone https://github.com/christopher-lu/christopherlu.dev.git
````

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
